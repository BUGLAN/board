# Board 原型

按 [docs/PRD.md](../docs/PRD.md) v0.3 实现的可交互原型，纯 HTML/CSS/JS，无构建步骤、无依赖。

## 打开

- 直接双击 `index.html`；或
- `python3 serve.py`，然后访问 http://localhost:5178（禁用缓存。可以开多个窗口观察实时同步）

## 项目与白板

一个项目下可以有多块白板（1 : N），每块白板有名字和标识，用「项目/白板」定位，例如 `oss/release`。卡片编号、「一个 agent 同时只持有一张卡片」、超时释放都在每块白板内独立计算。

- **活动栏「项目」**（第二个图标）：侧栏是项目 → 白板的树，点白板打开；⋯ 菜单里新建白板、编辑、改颜色、管理标签、删除。主区域是**无限画布**：项目节点连线到它的白板节点，有 agent 在工作的连线会流动。拖动空白处平移，`⌘/Ctrl` + 滚轮缩放，拖动节点调整位置，双击白板打开，双击空白处新建项目，项目节点右侧的 `+` 新建白板。
- **顶栏切换器**（`P`）：按项目分组列出所有白板，搜索后回车切换。每个窗口可以看不同的白板。
- **CLI**：白板由 `--board <项目>/<白板>` 或环境变量 `BOARD` 给出，必填；项目只有一块白板时可以只写项目标识。`board boards` 列出所有白板。缺少返回 `NO_BOARD`，不存在返回 `BOARD_NOT_FOUND`。

## 标签

- 标签属于项目，项目下所有白板共用；一张卡片可以有多个标签。人和 agent 都能加标签，「进行中」的卡片也可以（标签是整理用的元数据，不受持有者独占限制）。
- 网页：卡片详情里加 / 去标签（`L`），输入不存在的名称直接新建；新建卡片时也能选。白板侧栏的「标签」分组显示使用数，点一下按标签筛选（等价于在筛选框输入 `label:名称`）。「管理标签」里改名、改色、删除（删除会从所有卡片上移除）。
- CLI：`board label <ID> +bug -文档`、`board ls --label bug`、`board labels`。

## 复制为提示词

- 卡片详情右上角「复制为提示词」（`C`）：任务、标签、描述、最近动态，以及处理这张卡片要执行的 `board` 命令（已带上 `BOARD=项目/白板`）。「未整理」的条目会生成「帮我整理成可执行卡片」的提示词。
- 白板页头「复制为提示词」/ 白板 ⋯ 菜单：执行 agent 的工作循环 + 当前待办列表。
- 复制后可以在 toast 里点「预览」查看和修改。

## 布局

左右分栏，类似 VS Code：

```
┌──────────────── 顶栏：品牌 · 搜索 / 命令面板 · 实时状态 · 正在工作的 agent ────────────────┐
│ 活动栏 │ 侧栏                    │ 主内容区                                                │
│  白板  │ 白板概览：筛选 / 列 / 正在工作 / 最近动态 │ 白板（四列）                               │
│ 未整理 │ 未整理条目：记录 / 拖到「待办」          │ 白板（四列）                               │
│  设置  │ 设置目录                              │ 设置页                                     │
│        │                                     ├── 模拟 CLI（仅演示）────────────────────────│
└────────────────────────────── 状态栏 · 演示工具（仅原型） ──────────────────────────────────┘
```

- 再次点击当前 Tab，或按 `⌘B` / `Ctrl B`：收起 / 展开侧栏；拖动侧栏右边缘调整宽度，双击还原。
- **未整理**：放在「待办」之前、还没整理清楚的计划和想法。不显示在白板上，agent 也不会领取。整理好后拖到「待办」，或点条目上的「整理到待办」。
- **新建**：白板和「未整理」的新建都在同一个居中弹窗里完成（与卡片详情同一套尺寸）。
- 手机：活动栏变为底部 Tab 栏；「未整理」占满内容区；白板各列左右滑动；卡片详情为底部 sheet，可下拉关闭。

## 演示专用（正式产品不包含）

带「演示」标记的部分只为原型演示存在：

- 页面底部的**模拟 CLI 终端**与**模拟 agent**（`js/sim/`）。正式产品里 agent 在自己的环境中直接运行 `board` 命令。
- 状态栏右侧的**演示时钟**（×1 / ×10 / ×60）和 **Web / 桌面外壳切换**，以及「设置 → 演示工具」。

去掉 `index.html` 里加载 `js/sim/*` 的两行，页面会自动隐藏这些演示控件。

| 想看 | 怎么做 |
|---|---|
| 项目总览 | 活动栏第二个图标：项目树 + 无限画布；示例有 3 个项目、5 块白板 |
| 切换白板 | 按 `P` 或点顶栏「项目 / 白板」 |
| 标签 / 提示词 | 打开任意卡片：`L` 加标签，`C` 复制为提示词 |

| 拖拽违规弹回 | 把「待办」的卡片拖进「进行中」，或拖动 agent 正持有的卡片 |
| 筛选 | 「白板」侧栏顶部输入关键词，不匹配的卡片会淡出 |
| CLI 与网页同步 | 按 `` ` `` 打开模拟终端，执行 `board new "x"`、`board claim` |
| 超时释放 | 演示时钟调到 ×60，在「模拟 agent」里点某个 agent 的「掉线」 |
| 卡片详情 | 点任意卡片：居中弹窗（920×640），左边是内容，右边是动态和评论；`↑↓` / `K J` 切换同列的上一张 / 下一张 |
| 强制释放 / 删除 | 点开「进行中」的卡片 |

快捷键：`P` 切换白板 · `⌘1/2/3/4` 切换 Tab（白板 / 项目 / 未整理 / 设置） · `⌘B` 侧栏 · `⌘K` 命令面板 · `N` 新建卡片 · `I` 记一条未整理 · `Esc` 关闭 · 卡片上 `↑↓←→` 切换、`Enter` 打开。

## 结构

```
index.html            外壳：顶栏 / 活动栏 / 侧栏 / 主内容区 / 演示终端 / 状态栏 / 浮层
css/
  tokens.css          设计 token：颜色、字体、动效曲线、尺寸；浅色 / 深色主题
  base.css            重置、背景氛围、按钮 / 输入 / 头像等基础控件
  layout.css          应用网格、顶栏、状态栏
  workbench.css       活动栏、侧栏、白板概览树、未整理、演示标记
  board.css           列、卡片、拖拽状态、新建入口
  settings.css        设置页，以及卡片密度 / 动效偏好
  overlays.css        卡片详情弹窗、命令面板、确认框、toast
  console.css         模拟终端与模拟 agent（演示）
  platform.css        桌面端外壳、平板 / 手机断点
js/
  core/schema.js      列（含「未整理」）、领取时长、错误码
  core/engine.js      规则引擎：纯函数 apply(state, cmd, now)，不碰 DOM
  core/store.js       Store（多项目工作区）+ Transport（持久化与同步）+ 可加速的时钟 + 示例数据
  cli/cli.js          board 命令解析与输出（文本 / --json）
  ui/workbench.js     活动栏 Tab、侧栏视图、设置页
  ui/creator.js       新建弹窗（白板 / 未整理共用）
  ui/projects.js      项目树、白板切换器、新建 / 编辑 / 删除项目与白板
  ui/canvas.js        项目总览无限画布
  ui/labels.js        标签选择器与标签管理
  ui/prompt.js        复制为提示词
  ui/*.js             白板、拖拽、详情、命令面板等
  sim/*.js            演示专用：模拟终端、模拟 agent
  app.js              组装与启动
```

## 扩展点

- **新增 Tab**：在 `workbench.js` 的 `TABS` 登记，并在 `index.html` 加一个 `.ab-item` 与 `.side-view`。
- **接后端**：实现与 `LocalTransport` 相同的 `read / write / subscribe` 接口（REST + SSE / WebSocket，或每秒轮询 `rev`），在 `app.js` 里替换即可。规则引擎可以原样搬到服务端。
- **桌面端**：`js/ui/platform.js` 识别 Electron / Tauri，自动切到桌面外壳（顶栏即标题栏）；原生能力挂在 `platform.bridge` 上。
- **主题**：在 `tokens.css` 追加 `:root[data-theme="xxx"]` 覆盖变量。
- **命令面板**：`Board.palette.register({ title, icon, run })` 追加命令。
- **事件**：`Board.ui.bus.on('card:open' | 'tab:changed' | 'count:changed' | 'board:rendered', fn)`。

## 与正式产品的差异

- 数据存在浏览器 localStorage；超时扫描由打开的页面执行（正式产品应由服务端执行）。
- 模拟终端、模拟 agent、演示时钟、外壳切换只用于演示，PRD 里不包含。
- Markdown 是简化实现，正式实现应换成成熟的解析库。
